# Harness — записки по проекту

Агент для работы с кодом: Java 25, Spring Boot 4, Spring AI 2.
Модель локальная, Ollama на порту 11431.

## Как собирать и запускать

```
.\mvnw.cmd test                  быстрые тесты
.\mvnw.cmd -DskipTests package   сборка исполняемого jar
java -Dstdout.encoding=UTF-8 -jar target/harness-0.1.0-SNAPSHOT.jar
```

Maven в PATH нет — только обёртка `mvnw`.
На Windows указывай префикс `.\`: текущая папка не добавляется в поиск команд.
Если команда завершилась ошибкой, прочитай вывод и исправь причину. Повторять
неизменённую неработающую команду бесполезно.
Для вопросов о разрешениях нужен интерактивный stdin: запускай main в IDEA
или собранный jar в терминале.

## Договорённости

* Ошибка инструмента — это результат, а не исключение. Инструмент возвращает
  `ToolResult.error(...)` с текстом, по которому видно, что делать дальше.
* `WorkspaceGuard` нормализует путь и проверяет symlink. Доступ определяет
  `PathInspector`: учитывает рабочие каталоги, правила и выбранный режим.
  Внешний путь можно разрешить явно; сам абсолютный путь разрешения не даёт.
* Править файл можно только после его чтения — за этим следит `FileStateCache`.
* Deprecated API Spring AI не используем: проект стоит на версии 2.0,
  старые сигнатуры из 1.x не берём.
* Пакет `hud` — только представление. Ядро агента про него не знает
  и импортировать его не должно.
