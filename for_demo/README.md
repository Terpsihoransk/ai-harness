# Урок 0 — спросить модель из терминала

Команда. Копировать целиком, запускать **из корня проекта** (терминал IDEA — `Alt+F12`):

```
curl.exe -s -X POST http://localhost:11432/api/generate -H "Content-Type: application/json" --data-binary "@lesson-00/ask.json"
```

Тело запроса лежит рядом — `ask.json`.

---

**Почему вопрос в файле, а не прямо в команде.** Русский текст, набранный в терминале
Windows, доезжает до модели битым: она отвечает не на то, о чём её спросили.
Файл в UTF-8 такой проблемы не создаёт.

**Почему `curl.exe`, а не `curl`.** В PowerShell `curl` — это псевдоним
`Invoke-WebRequest` с другими ключами, и команда просто не отработает.

**Почему порт 11432.** Так задано в `docker-compose.yml` — чтобы не столкнуться
с Ollama, которая уже может быть установлена у вас.

Первый запрос после старта контейнера идёт заметно дольше: модель загружается
в видеопамять. Второй такой же — около двух секунд.
